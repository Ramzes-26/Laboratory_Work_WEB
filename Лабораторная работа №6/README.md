\# ✦ NEXUS — Dashboard



Адаптивная панель управления бизнесом, разработанная в рамках лабораторной работы по теме \*\*«Макетирование и адаптивность: Flexbox, Grid и Mobile First»\*\*.



\## 📌 О проекте



NEXUS — это современный макет CRM-панели с тёмным оформлением, статистикой, графиком продаж и таблицей заказов.



Проект создан с помощью HTML5 и CSS3 без использования JavaScript.



\## ✨ Основные элементы



\- Боковое меню навигации.

\- Шапка с профилем пользователя.

\- Карточки статистики.

\- График продаж за неделю.

\- Блок последних событий.

\- Таблица последних заказов.

\- Hover-эффекты и анимации.



\## 🛠 Технологии



\- HTML5

\- CSS3

\- Flexbox

\- CSS Grid

\- Media Queries

\- Mobile First

\- БЭМ

\- CSS Variables

\- clamp()

\- minmax()

\- Keyframes



\## 📱 Адаптивность



Проект поддерживает три размера экрана:



\- Мобильные устройства — до 600px.

\- Планшеты — от 600px до 1024px.

\- Компьютеры — от 1025px.
