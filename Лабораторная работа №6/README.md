# ✦ NEXUS — Dashboard

Современная адаптивная панель управления (CRM Dashboard), созданная в рамках лабораторной работы по теме **«Макетирование и адаптивность: Flexbox, Grid и Mobile First»**.

## 📌 О проекте

NEXUS — это макет панели управления бизнесом с тёмным дизайном, карточками статистики, графиком продаж и таблицей последних заказов.

Проект выполнен с использованием HTML5 и CSS3 без JavaScript и дополнительных библиотек.

## ✨ Возможности интерфейса

- Боковая панель навигации (Sidebar).
- Шапка с приветствием и профилем пользователя.
- Карточки с финансовой статистикой.
- График продаж за неделю.
- Блок последних событий.
- Таблица последних заказов.
- Hover-эффекты и CSS-анимации.

## 🛠 Используемые технологии

- **HTML5** — структура страницы.
- **CSS3** — оформление и стилизация.
- **Flexbox** — расположение элементов и навигация.
- **CSS Grid** — создание основной сетки интерфейса.
- **Media Queries** — адаптация под разные размеры экранов.
- **Mobile First** — подход к адаптивной вёрстке.
- **БЭМ** — организация CSS-классов.
- **CSS Variables** — переменные для цветов и оформления.
- **Clamp() и Minmax()** — адаптивные размеры и сетки.
- **Keyframes** — CSS-анимация.

## 📱 Адаптивность

Интерфейс адаптируется под три типа устройств:

- 📱 Телефоны — до 600px.
- 📲 Планшеты — от 600px.
- 💻 Компьютеры — от 1025px.
